# Папка для пользовательских изображений

Здесь живут фото, которые вы сами подберёте для пригласительной.

## Какие файлы подхватывает `index.html`

| Файл | Где используется | Рекомендация |
|------|------------------|--------------|
| `groom.jpg` | Круглый портрет жениха в hero (левая рамка, подпись «Ринат · Жених») | Квадрат 600×600 px, по плечи |
| `bride.jpg` | Круглый портрет невесты в hero (правая рамка, подпись «Дарина · Невеста») | Квадрат 600×600 px, по плечи |
| `couple.jpg` | Круглый портрет пары в финальной секции | Квадрат 600×600 px |
| `love-bg.jpg` | Кастомный фон секции «Любовь» (растворяется в кремовый сверху/снизу) | Горизонтальный, ~1920×1080 px, пастельный |
| `bg2.jpg` | Второй кастомный фон секции «Вместе» (между обратным отсчётом и финалом) | Горизонтальный, ~1920×1080 px |

> Если файла нет — на его месте остаётся аккуратный SVG‑силуэт с монограммой (Р/Д). «Битых картинок» не будет.

## Поддерживаемые форматы

Сайт **автоматически** попробует альтернативные расширения, если основное не найдено. Поэтому подойдёт любой из:
- `.jpg` / `.jpeg` / `.JPG`
- `.png` / `.PNG`
- `.webp`

Просто сохраните файл под тем именем, что указано выше (`groom`, `bride`, `couple`, `love-bg`, `bg2`) — расширение подберётся автоматически.

## Если фото всё равно не появилось

Чек-лист:
1. Файл лежит ровно в `images/` рядом с `index.html`, а не на рабочем столе / в загрузках.
2. Имя файла совпадает **посимвольно** (`groom.jpg` ≠ `Groom.jpg` ≠ `риnat.jpg`).
3. Размер не гигантский (до 1–2 МБ оптимально). Браузер сам сожмёт, но файл >5 МБ может долго грузиться.
4. Сделайте **жёсткую перезагрузку** страницы: `Ctrl + Shift + R` (или `Cmd + Shift + R` на Mac) — без этого браузер покажет старую HTML без тега `<img>`.
5. Откройте DevTools → Console — если фото не найдено, там будет предупреждение `[invite] Фото не найдено: …` с указанием пути.

## Бонус — свои фоны для других секций

Хотите фон для других секций (venue/rsvp/countdown)? Положите файл (например `flowers-bg.jpg`) и попросите помощника подключить его в нужный `.section` через CSS `background-image: url('images/flowers-bg.jpg')` — у всех пользовательских секций уже работает плавное растворение в кремовый сверху/снизу.
